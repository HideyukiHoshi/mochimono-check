# もちもちもちもの v1.5
iPhone 8 / iOS 16.7.16 を想定した、オフライン対応PWAです。SafariでGitHub PagesのURLを開き、「ホーム画面に追加」して使います。

## 主な機能
- QRコードで持ち物をチェック
- もちもちした持ち物キャラが部屋をうろうろする
- スキャン時に、そのキャラが喜ぶポップアップを数秒表示
- 「今日はもって帰らなくてよかった」ボタン
- カレンダーで日ごとの確認状況を表示
- 保護者用PINロックつき管理画面
- 持ち物ごとの曜日設定
- 既成イラスト種類 + 文字キャラ（先頭文字に顔つき）

## 使い方メモ
1. 保護者設定（⚙︎）からPINを設定
2. 持ち物を追加し、必要な曜日を設定
3. 各持ち物の「QR」ボタンからQRコードを表示・保存・印刷
4. 子どもはホームでQRをスキャンするか、「今日はもって帰らなくてよかった」ボタンを押す
5. カレンダーで日ごとの結果を確認

## 注意
- QR生成・QRスキャン用ライブラリは初回オンライン時に取得し、Service Workerでキャッシュします。
- キャッシュが古い場合は、Safariで公開URLをオンラインの状態で1回再読込してください。
